# usazxmoto.com

Static landing page for **usazxmoto.com** — a premium domain offered for sale to the motorcycle / powersports industry.

- **Contact:** lan.huang.urbantzer@gmail.com
- **Hosting:** GitHub Pages
- **Custom domain:** `usazxmoto.com` (see `CNAME`)

## Deploy

Single self-contained `index.html` + `CNAME`. Pushed to the `main` branch; GitHub Pages serves from root.

Three.js is loaded from jsDelivr via an import map (no build step, no dependencies).
